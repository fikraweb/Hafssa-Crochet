# Recessed boutique product cards

The supplied reference is implemented as a CSS display niche: thick ivory card/rim, shaded arched rear wall, soft directional product shadow, raised wooden shelf, hanging paper category tag, serif product name, real price and rose add-to-cart action with shopping bag icon. A small perspective tilt on hover is an explicit exception to the Taste default against tilt: the user specifically requested cards that look 3D. No WebGL, 3D engine or pointer-tracking loop was introduced.

All 83 known catalogue covers use responsive derivatives of their existing alpha-only cutouts, keyed by the original photo URL in card-images.js. Source photos, cutouts, prices, catalogue order and original dialog galleries remain unchanged. A changed/uploaded image without a known cutout falls back to its original/optimized photo instead of showing a stale or missing image. New derivative sizes are capped at 600x720 without upscaling; sources are preserved. Build validates that every referenced derivative exists.

Only factual information is printed. The reference's materials, dimensions and organic cotton claims were not invented; cards say “Création faite main”. No inactive favorite/heart control was added. Existing preview/gallery/add handlers and accessible labels are retained. Mobile uses two columns, full-width 44px add buttons and at least 44px gallery/preview targets. The tag sits outside the photo clipping boundary so its text remains visible.

Validation: npm test 7/7; build and JS syntax/whitespace checks passed; 1,631-file upstream Taste integrity verified. A local browser regression exercised actual cards at 1440/820/390/320, decoded original-derived covers, verified category labels and no horizontal overflow, preview dialog, add-to-cart, filter and price-sort behavior, and zero uncaught JS errors. No production orders were created. Desktop/mobile screenshots were reviewed; clipped tags and inconsistent inherited corner radii were corrected and checks rerun. The existing full Taste gate is not claimed to pass; this change is a targeted card redesign.
